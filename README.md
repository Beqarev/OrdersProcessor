# Orders Processor

კონსოლური აპლიკაცია (C# / .NET 10), რომელიც ამუშავებს `orders.json` ფაილს:

1. აჩვენებს ყველა შეკვეთას;
2. ეძებს კონკრეტული მომხმარებლის შეკვეთებს;
3. სტატისტიკის დათვლისას გამოტოვებს გაუქმებულ შეკვეთებს;
4. დასრულებული შეკვეთებისთვის ითვლის რაოდენობას, გაყიდვების ჯამს, საშუალო შეკვეთის ღირებულებას და ყველაზე პოპულარულ პროდუქტს (გაყიდული რაოდენობის მიხედვით).

## როგორ გავუშვათ

საჭიროა [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
# ინტერაქტიული მენიუ
dotnet run --project OrdersProcessor

# ან პირდაპირ ბრძანებით
dotnet run --project OrdersProcessor -- list
dotnet run --project OrdersProcessor -- customer Nino
dotnet run --project OrdersProcessor -- stats

# სხვა JSON ფაილით
dotnet run --project OrdersProcessor -- --file path/to/orders.json stats

# ტესტები
dotnet test
```

ნაგულისხმევად გამოიყენება `OrdersProcessor/Data/orders.json`. build-ისას ის output საქაღალდეში კოპირდება.

## სტრუქტურა

```
OrdersProcessor/
├── Data/orders.json
├── Models/          Order, OrderItem, OrderStatistics
├── Services/
│   ├── OrderLoader.cs    JSON-ის წაკითხვა და ვალიდაცია
│   └── OrderService.cs   სია, ძებნა, სტატისტიკა
└── Program.cs       მენიუ და ბრძანებები (მხოლოდ შეტანა და გამოტანა)
OrdersProcessor.Tests/   xUnit ტესტები (22 ტესტი)
```

ლოგიკა (`OrderService`, `OrderLoader`) Console-ზე დამოკიდებული არ არის, ამიტომ ის ტესტებით პირდაპირ მოწმდება. კონსოლური ფორმატი შეგნებულად ავირჩიე: დავალება სერვერს ან UI-ს არ მოითხოვს. საჭიროების შემთხვევაში იგივე სერვისებზე Web API-ის დაშენება `Program.cs`-ის შეცვლით არის შესაძლებელი.

## ტესტები

- გაუქმებული შეკვეთები სტატისტიკაში არ შედის;
- ჯამი და საშუალო სწორად ითვლება (საშუალო გამოითვლება შეკვეთაზე და არა ერთეულზე);
- პოპულარული პროდუქტი განისაზღვრება რაოდენობით და არა შემოსავლით;
- ფრის შემთხვევაში ბრუნდება ყველა თანაბარი პროდუქტი;
- დასრულებული შეკვეთების არქონისას ნულზე გაყოფა არ ხდება;
- სტატუსის შედარება დიდ/პატარა ასოებსა და ზედმეტ ჰარებს არ არჩევს;
- მომხმარებლის ძებნა (რეგისტრი, ჰარები, ნაწილობრივი სახელი, ცარიელი შეყვანა);
- ინტეგრაციული ტესტი რეალურ `orders.json`-ზე, ხელით დათვლილი მნიშვნელობებით;
- არავალიდური JSON, უარყოფითი რაოდენობა ან ფასი, ცარიელი პროდუქტის სახელი, `items: null` და არარსებული ფაილი.
